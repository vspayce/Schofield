# Schofield

A third-person western stagecoach shooter for the browser — built for phones in
landscape, plays great on desktop too. Ride shotgun on the Overland Mail across
four routes (prairie, mountain pass, a ghost town, a red-rock canyon) and fight
off riders and ridge riflemen with a Schofield revolver or a coach gun.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

Pushing to `main` publishes the game to https://vspayce.github.io/Schofield/ via
`.github/workflows/deploy.yml` (Settings → Pages → Source must be "GitHub Actions").

Debug: `?route=0..3&weapon=shotgun` jumps straight into a ride.

See `DESIGN.md` for the design, asset contracts and code layout. Every asset is
generated by scripts in `tools/` (Blender, Python) so it can be rebuilt.

After rebuilding any model with `tools/blender/build_*.py`, run `sh tools/pack_models.sh` to meshopt-compress the GLBs.
